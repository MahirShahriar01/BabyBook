# 🌐 Kids Explorer AI — Website

React 18 + Vite + Framer Motion. Animated, kid-friendly, works offline, no sign-up.

## Run
```bash
npm install
npm run dev        # http://localhost:5173
npm test           # engine, sudoku, AI-lab and content tests (node:test)
npm run lint
npm run build      # → dist/ (static, deploy anywhere over HTTPS)
```
Windows/macOS setup details: [../docs/BUILD_GUIDE.md](../docs/BUILD_GUIDE.md).

## Environment (`.env`, all optional)
| Variable | Description |
|---|---|
| `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` | Live content from the admin panel + anonymous analytics |
| `VITE_CONTENT_URL` | Static `content.json` exported from the admin panel (when not using Supabase) |
| `VITE_BUDDY_AI_URL` | Fallback URL for the optional buddy cloud AI (admin setting wins) |

## Structure
```
src/
  App.jsx                 routes (HashRouter), feature guards, screen-time overlay
  store/AppContext.jsx    content + profile + progress, complete() reward loop
  lib/
    content.js            seed → cache → Supabase / JSON loader
    theme.js              admin theme modes → CSS variables
    buddyEngine.js        Talking Buddy correction engine (on-device)
    speech.js             Web Speech API (TTS + recognition)
    recognizer.js         $1 shape recognizer, k-NN, next-item predictor (AI Lab)
    sudoku.js             puzzle generator / validator
    progress.js           local storage, levels, daily missions
    analytics.js          anonymous batched events
    sound.js              Web Audio sound effects (no files)
    i18n.js               English / বাংলা interface strings
  components/             UI kit, TraceCanvas, SayIt pronunciation widget
  pages/                  Onboarding, Home, Alphabet, Stories, StoryReader, Videos, Games (+5 games),
                          Explore, Topic, Quiz, Buddy, AiLab, Rewards, Parents
  data/seed.json          generated by ../scripts/sync-content.mjs
```

## Browser support
Chrome, Edge, Safari, Firefox (latest). Voice input needs Chrome/Edge/Safari; typing works everywhere. Respects `prefers-reduced-motion`.
