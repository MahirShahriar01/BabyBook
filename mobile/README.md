# 📱 Kids Explorer AI — Android App (Flutter)

Google Play–ready Flutter app with child-directed AdMob, on-device speech and the same content and design as the website.

## Requirements
Flutter **3.47+** (stable), Android Studio with Android SDK, JDK 17 (bundled with Android Studio). Min Android: **7.0 (API 24)** (Google Mobile Ads requirement).
Step-by-step for **Windows & macOS**: [../docs/BUILD_GUIDE.md](../docs/BUILD_GUIDE.md).

## Run & test
```bash
flutter pub get
flutter run                     # emulator or USB device
flutter analyze                 # no issues
flutter test                    # 52 tests: engine parity, games, every screen at phone size, onboarding flow
```

### Play Store screenshots without a device
```bash
flutter test --tags screenshots --run-skipped --update-goldens
# → test/store_screenshots/screenshots/*.png (1080×2160, real screens, real fonts)
```
Colour emoji need Noto Color Emoji: `EMOJI_FONT=/path/to/NotoColorEmoji.ttf` (on Linux it's found automatically).

## Configuration (`--dart-define`, all optional)
| Key | Description |
|---|---|
| `SUPABASE_URL`, `SUPABASE_ANON_KEY` | Live content from the admin panel + anonymous analytics |
| `CONTENT_URL` | Static `content.json` exported from the admin panel |

Gradle property / env var `admobAppId` / `ADMOB_APP_ID` → AdMob **App ID** in the manifest (defaults to Google's test ID).
Ad **unit IDs**, on/off switches, frequency and test mode are controlled from **Admin → AdMob**.

## Release
```bash
cp android/key.properties.example android/key.properties   # fill in your keystore
flutter build appbundle --release -PadmobAppId=ca-app-pub-XXX~YYY \
  --dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...
```
Play Console, Families policy and Data safety answers: [../docs/PLAY_STORE_RELEASE.md](../docs/PLAY_STORE_RELEASE.md).

## Structure
```
lib/
  main.dart                    app, theme from admin settings, screen-time & break overlays
  i18n.dart                    English / বাংলা interface strings
  models/content.dart          typed views over the shared JSON content
  state/app_state.dart         profile, stars, stickers, missions, streak (SharedPreferences)
  services/
    content_service.dart       seed → cache → Supabase / content.json
    buddy_engine.dart          Talking Buddy engine (Dart port, parity-tested with web)
    speech_service.dart        flutter_tts + speech_to_text (device speech, free)
    ads_service.dart           AdMob child-directed config, banner slot, interstitial pacing, rewarded
    analytics.dart             anonymous batched events
    logic.dart                 sudoku, k-NN, predictor, shape recognizer
  widgets/                     KidScaffold, animated tiles & emojis, confetti, parental gate, SayIt, TracePad
  screens/                     onboarding, home map, alphabet, stories, videos, games (5), explore, quiz,
                               buddy, AI lab, rewards, grown-ups
assets/content/seed.json       generated by ../scripts/sync-content.mjs
```

## Families-policy summary
`ageRestrictedTreatment: child`, max rating G, `nonPersonalizedAds: true`, `AD_ID` permission removed, no accounts, data stays on device, parental gate before grown-up areas and rewarded ads, no outbound links, mic only on tap.
